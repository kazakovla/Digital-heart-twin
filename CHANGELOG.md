# Журнал изменений

## Версия 2 — исправления по замечаниям руководителя практики

### Критические ошибки

1. **Неверная ориентация нормалей эндокарда (`src/prepare_meshes.py`).**
   Нормали граничных граней ориентировались «от центра сетки». Для внутренних
   поверхностей (эндокард ЛЖ и ПЖ) это неверно: внешняя нормаль миокарда там
   смотрит в полость. Около 90 % граней эндокарда были перевёрнуты, и давление
   в полостях **сжимало** сердце (объём выпуклой оболочки уменьшался на 2–22 %)
   вместо диастолического наполнения. Весь набор решений КЭА v1 и обученная на
   нём модель были физически неверны.
   - Нормаль теперь определяется по противолежащей вершине тетраэдра
     (`outward_orient(coords, faces, elements)`).
   - Скрипт `src/fix_face_orientation.py` исправляет уже подготовленные
     `data/geom/*.npz` без повторной загрузки с Zenodo.
   - В `src/generate_dataset.py` добавлен физический контроль: объём каждой
     полости обязан расти под давлением, иначе расчёт прерывается.
   - Набор `data/fea/*.npz` пересчитан (11 сердец × 16 решений).

2. **Расходящийся решатель Лапласа–Дирихле (`heartsim_sage.py`).**
   В итерационной схеме в числитель попадало собственное значение узла:
   (φᵢ + Σφⱼ)/deg вместо Σφⱼ/deg. На цепочке из 11 узлов функция давала `inf`,
   на реальной сетке — значения до 3·10³⁸. Заменено точным решением
   разреженной системы; проверено на цепочке (точный ответ 0; 0,1; …; 1) и на
   реальной сетке (корреляция φ_AB с UVC-координатой — 0,975).

3. **Неверные пороги страт (`heartsim_sage.py`, `src/graph_features.py`).**
   По [15] Q_p% — перцентили *всех попарных* расстояний между узлами. В коде
   они считались по 199 ближайшим соседям, и дальняя страта заканчивалась на
   6,7 мм вместо 30,3 мм — дальнодействующих связей не было. Исправлено.

### Существенные исправления

4. Внимание (`heartsim_sage.py`): запрос теперь формируется из узла-получателя,
   ключи и значения — из рёбер; раньше ребро «сравнивалось само с собой».
5. Обучение на подмножестве N_S узлов действительно экономит вычисления
   (`target_idx`): сообщения и декодер считаются только для N_S узлов.
6. `personalize_beta` оптимизирует log β: раньше шаг Adam ≈ 0,01 при β ~ 10³
   практически не менял параметры, а β мог стать отрицательным.
7. Эксперимент (`src/train_hss.py`):
   - прореженный граф раньше состоял только из узлов поверхности —
     теперь узлы выбираются равномерно по объёму;
   - признаки и смещения переведены в анатомические оси сердца
     (длинная ось, направление ЛЖ→ПЖ) вместо координат томографа;
   - итоговая проверка — на **полных** сетках тестовых сердец; ускорение
     сравнивает КЭА и эмулятор на одной и той же сетке (раньше — КЭА на
     полной сетке против эмулятора на 24 % узлов);
   - профиль весов внимания по стратам считается по обученной модели.
8. Поля Лапласа в эксперименте приведены к составу и порядку из отчёта и [15].

### Иллюстрации и оформление

9. `generate_illustrations.py` не запускался (импорт несуществующего пакета
   `digital_heart_twin`) и рисовал случайное облако точек. Теперь все рисунки
   строятся на реальной сетке; рисунки с числами из статьи подписаны
   ссылкой [15].
10. Удалены неиспользуемые зависимости (`torch_geometric`, `fenics-dolfinx`);
    числа из статьи в комментариях помечены как результаты [15].
11. Результаты v1 сохранены в `results/hss_metrics_v1_invalid.json` только для
    истории; использовать их нельзя.
